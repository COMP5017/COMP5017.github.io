# COMP5017 Programming Principles and Practices

This repository contains the COMP5017 copy of the Programming Principles and Practices
practical worksheet site for Curtin University.

The lesson content is based on the shared COMP1005/COMP5017 materials and is
built with The Carpentries Workbench.

## Publishing

The included GitHub Actions workflow builds the lesson with sandpaper and
deploys it to GitHub Pages. For a `COMP5017.github.io` repository, configure
GitHub Pages to publish from the `gh-pages` branch after the first successful
workflow run.
